## 30 天成功标准（对照用）

### 合格（最低目标）
- [ ] 20+ 页面被 Google 收录
- [ ] Search Console 有 500+ impressions
- [ ] 3-5 个页面有自然点击
- [ ] 有 3 个以上外部社区访问来源
- [ ] 能看出哪些主题更有潜力

### 很好
- [ ] 总访问 300-800
- [ ] 自然搜索点击 50+
- [ ] 有一个工具页或文章被外部社区引用
- [ ] Google 开始展示 10 个以上相关查询词

### 超预期
- [ ] 总访问 1,000+
- [ ] 某篇文章或工具被社区转发
- [ ] 某个关键词开始稳定带点击

---

## 什么时候让 agent 做下一轮

出现以下情况，把数据发给 agent：

1. 某篇文章有曝光但 CTR 低 → 让 agent 改标题、描述、文章开头
2. 某个关键词反复出现 → 让 agent 加内容或写新文章
3. 某个工具页有访问 → 让 agent 加强内容
4. Google 报结构化数据错误 → 让 agent 修复
5. 社区里反复有人问同一类问题 → 让 agent 做专门文章
