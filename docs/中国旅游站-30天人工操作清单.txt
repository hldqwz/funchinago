中国旅游站 30 天人工操作清单
==============================

适用项目：China Travel Made Easy
目标：低成本把网站运营起来，先做收录、曝光、真实访问和内容可信度，不急着做广告、购物链接或付费外链。


一、第 1 周：完成收录和数据地基
------------------------------

你要做的事：

1. 登录 Google Search Console
2. 添加你的正式域名
3. 提交 sitemap
4. 登录 Bing Webmaster Tools
5. 添加网站
6. 确认 Cloudflare Analytics 能看到访问数据
7. 把验证成功或报错截图发给实施 agent

你需要告诉 agent：

- 正式域名是什么
- Google Search Console 是否验证成功
- sitemap 是否提交成功
- Bing Webmaster Tools 是否添加成功
- Google 是否报错
- Cloudflare Analytics 是否能看到访问

注意：

- 不用每天盯数据，刚上线前几天没有变化很正常。
- 建议每 2-3 天看一次 Search Console。
- 第一个月重点看“有没有被收录”和“有没有曝光”，不要急着看赚多少钱。


二、第 2 周：补充只有你能提供的本地经验
--------------------------------------

你不需要写正式文章，只要写短素材。每条 5-10 句话即可。

优先补充这些：

1. 外国游客在中国支付失败时，现实中通常怎么处理？
   例如：店员是否愿意等、能不能换支付方式、现金有没有用、朋友代付是否常见。

2. 第一次来中国，哪些城市最稳？
   例如：北京、上海、广州、成都、深圳、杭州，哪些适合第一次来，哪些不适合。

3. 高铁站和机场最容易让外国人困惑的地方是什么？
   例如：车站太大、安检、候车口、多个火车站名字相似、护照核验。

4. 扫码点餐不会中文怎么办？
   例如：让店员帮忙、使用翻译软件、选择有图片菜单的店、避开太复杂的小程序。

5. 哪些中国 App 对外国游客最关键？
   例如：支付宝、微信、翻译、地图、铁路/订票、酒店、打车。

6. 哪些网红城市好看但不适合第一次来？
   例如：交通复杂、英语支持弱、景点分散、过度依赖本地 App 的地方。

7. 外国人对中国旅行最容易误解什么？
   例如：以为信用卡到处能用、以为英文服务普遍、以为没有现金就没问题、以为一个 App 能解决所有事。

怎么交给 agent：

- 可以直接发文字
- 不用英文
- 不用排版
- 不用很完整
- 真实经验比漂亮文字更重要


三、第 3 周：开始低强度外部曝光
------------------------------

每天 20-30 分钟即可，不要做成压力很大的任务。

你要做的事：

1. 找 1 个外国游客关于中国旅行的问题
2. 认真回答问题
3. 不要一上来就贴网站链接
4. 如果对方问题正好对应你的文章或工具，再自然附上一句链接
5. 把发过的平台、问题、链接记录下来

优先回答的问题：

- Can I use Alipay in China as a foreigner?
- Do I need cash in China?
- Is the 240-hour visa-free transit enough for my route?
- Which Chinese city should I visit first?
- Do I need a VPN or eSIM for China?
- How do I book high-speed trains in China?
- Is China hard to travel without speaking Chinese?
- What apps should I download before going to China?

适合找问题的平台：

- Reddit 旅行相关社区
- Tripadvisor Forum
- Quora
- Facebook travel groups
- Expat / digital nomad 社区
- 来华留学或来华旅行相关论坛

不要做：

- 不要买外链
- 不要刷访问
- 不要复制粘贴同一段回答
- 不要在无关论坛硬贴链接
- 不要用夸张标题骗点击
- 不要注册一堆小号发链接


四、每周数据复盘
----------------

建议每周日晚上看一次。

你要记录这些：

- Google 收录页面数
- Search Console impressions
- clicks
- CTR
- 平均排名
- 前 10 个搜索词
- 点击最多的 5 个页面
- 哪些外部社区带来访问
- 哪篇文章下周值得继续加厚

怎么判断数据：

第一个月如果没有大流量，不代表失败。

健康信号是：

- 页面开始被 Google 收录
- Search Console 开始出现查询词
- 有少量自然点击
- 有人从社区点进来
- 某几个主题明显比其他主题更容易获得曝光


五、什么时候让 agent 继续做下一轮
--------------------------------

出现这些情况，就可以让 agent 继续推进：

1. 某篇文章有曝光但 CTR 低
   让 agent 改标题、描述、文章开头和内链。

2. 某个关键词反复出现
   让 agent 围绕这个关键词加内容，或做一篇更精确的新文章。

3. 某个工具页有人访问
   让 agent 加真实使用场景、相关文章入口和更清晰的说明。

4. Google 报结构化数据错误
   让 agent 修 JSON-LD 或页面内容。

5. 社区里反复有人问同一类问题
   让 agent 做一篇专门文章，或者把现有文章加厚。


六、30 天成功标准
----------------

合格：

- 20+ 页面被 Google 收录
- Search Console 有 500+ impressions
- 3-5 个页面有自然点击
- 有 3 个以上外部社区访问来源
- 你能看出哪些主题更有潜力

很好：

- 总访问 300-800
- 自然搜索点击 50+
- 有一个工具页或文章被外部社区引用
- Google 开始展示 10 个以上相关查询词

超预期：

- 总访问 1,000+
- 某篇文章或工具被社区转发
- 某个关键词开始稳定带点击


七、之后 60 天方向
-----------------

如果第一个月数据健康：

1. 第 2 个月重点加厚表现最好的 5 个页面
2. 第 2 个月继续补中国本地经验内容
3. 第 2 个月围绕支付、交通、城市选择、App 使用做更多实用文章
4. 第 3 个月再考虑 AdSense 前置准备
5. affiliate、购物链接、广告等有稳定访问后再谈

当前最重要的不是赚钱，而是让 Google 和真实用户相信这个站有用。
