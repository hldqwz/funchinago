## 三、今天新增完成的内容

### 1. 域名切换已经提前做成“一键修改”

我已经新增好了命令：

```bash
npm run set-site-url -- https://你的正式域名
```

它会自动修改：

- `astro.config.mjs`
- `public/robots.txt`

这意味着你明天买完域名后，不需要手工去两个文件里慢慢改。
