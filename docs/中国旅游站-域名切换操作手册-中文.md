# 中国旅游站域名切换操作手册

这份文档是给你明天买完域名之后直接照着做的。

目标只有一个：

- 尽量少改东西
- 尽量不出错
- 让网站继续保持在 `GitHub + Cloudflare Pages` 上运行

## 先说结论

你现在不需要买服务器。

当前最合适的方案是：

- 代码继续放在 GitHub
- 网站继续部署在 Cloudflare Pages
- 只新增一个正式域名

## 当前项目状态

当前线上地址：

- 根站：`https://llm-rankings.pages.dev/`
- 中国旅游主页：`https://llm-rankings.pages.dev/china-travel/`

当前仓库：

- `https://github.com/hldqwz/llm-rankings`

## 明天真正需要改的地方

核心只有 2 个文件：

1. `astro.config.mjs`
2. `public/robots.txt`

不过我已经帮你做好了更省事的方式。

你明天不需要手动打开这两个文件逐个改，只需要运行一条命令：

```bash
npm run set-site-url -- https://你的正式域名
```

例如：

```bash
npm run set-site-url -- https://example.com
```

它会自动帮你更新：

- `astro.config.mjs`
- `public/robots.txt`

## 明天的推荐操作顺序

### 第 1 步：在 Cloudflare Pages 里绑定域名

进入你现在的 `llm-rankings` Pages 项目：

- 添加自定义域名
- 等待 DNS 和 SSL 生效

## 第 2 步：在本地切换项目域名

运行：

```bash
npm run set-site-url -- https://你的正式域名
```

## 第 3 步：本地检查

运行：

```bash
node tests/chinaTravelArticles.test.mjs
node tests/chinaStarterPortalRoutes.test.mjs
npm run build
```

## 第 4 步：重新部署到 Cloudflare Pages

运行：

```bash
npx wrangler pages deploy dist/ --project-name=llm-rankings --branch=main --commit-dirty=true
```

## 第 5 步：检查正式域名是否正常

至少检查这几个页面：

- 首页
- 中国旅游首页
- 文章列表页
- 来源库页
- 2 到 3 篇重点文章

重点确认：

- 页面能打开
- 图片正常显示
- canonical 已经变成新域名
- sitemap 已经变成新域名

如果你想快速做一轮自动复查，还可以运行：

```bash
npm run verify-site-url -- https://你的正式域名
```

例如：

```bash
npm run verify-site-url -- https://example.com
```

它会帮你快速检查：

- 重点页面是否能打开
- canonical 是否已经切到新域名
- title 是否存在
- sitemap 是否正常

## 第 6 步：提交搜索引擎

域名稳定后再做：

- 提交 Google Search Console
- 提交 sitemap
- 有空再补 Bing Webmaster Tools

## 你现在不需要做的事

以下这些暂时都不用：

- 买服务器
- 配 Linux
- 配 Nginx
- 配 Docker
- 配数据库
- 配宝塔

## 最省事版本

如果你明天时间很紧，只做这几件事就够了：

1. 绑定域名
2. 运行 `npm run set-site-url -- https://你的正式域名`
3. 构建
4. 重新部署
5. 检查正式域名
