# FunChinaGo Image License Registry

Updated: 2026-07-28

## Purpose

This registry records the origin and reuse terms for real photographs used in FunChinaGo city guides. It is the shared image-rights format for Guangzhou, Chengdu, Shanghai, Beijing, Xi'an, and future city articles.

Before adding a city image:

1. Confirm that the original page states a reusable license.
2. Save the original source URL, author, and exact license name here.
3. Add the required credit in the article when the license requires attribution.
4. Do not use images copied from social media, review platforms, or personal blogs without explicit reuse permission.
5. Do not describe an image as public domain unless the source page explicitly says so.

## Maintenance

- Add one row for every new externally sourced city photograph.
- Use the filename stored under `public/china-travel/images/`.
- Link to the individual source file page, not a search-results page.
- Record license changes or replacements with a new `Updated` date.
- Backfill Guangzhou, Chengdu, Shanghai, and Beijing images when those articles are next edited; do not guess missing license data.
