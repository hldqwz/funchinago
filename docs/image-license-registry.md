## Purpose

This registry records the origin and reuse terms for every image stored under `public/china-travel/images/`. It is the shared image-rights format for Guangzhou, Chengdu, Shanghai, Beijing, Xi'an, Zhuhai, and future city articles.

On 2026-10-17 the whole folder was converted to WebP (PNG and large JPEG to WebP quality 82). Every row below uses the current on-disk filename. The six photographs that the automated article tests lock by filename (`beijing-jingshan-view.jpg` and the five `xian-*.jpg` files) were deliberately left in JPEG so those references stay valid.

Before adding a city image:

1. Confirm that the original page states a reusable license.
2. Save the original source URL, author, and exact license name here.
3. Add the required credit in the article when the license requires attribution.
4. Do not use images copied from social media, review platforms, or personal blogs without explicit reuse permission.
5. Do not describe an image as public domain unless the source page explicitly says so.
