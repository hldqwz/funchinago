# FunChinaGo

Independent Astro project for `https://funchinago.com`.

Includes:

- China Travel portal pages
- China travel article content
- tool pages and browser scripts
- China-specific docs and tests
- FunChinaGo deployment workflow

Main commands:

- `npm install`
- `npm run build`
- `node tests/chinaStarterPortalRoutes.test.mjs`
